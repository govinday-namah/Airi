# Airi

Airi is a mobile-first personal assistant PWA.

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features
- Mobile-friendly assistant interface
- Daily planning cards
- Task and schedule overview
- Airi chat interface
- PWA install support
- Offline caching via service worker

## Personality
Airi remains warm, elegant, witty, playful, and sometimes firm when needed.
