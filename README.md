# Airi

Airi is a mobile-first personal assistant PWA.

## Features
- mobile-friendly dashboard
- schedule and priority planning
- task tracker with local storage
- assistant chat interface
- installable app shell
- offline support via service worker

## Run locally
Serve the folder with a static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Install on phone
Open the page in a mobile browser and select "Add to Home Screen" or "Install" if available.

## Personality
Airi remains elegant, warm, witty, caring, and occasionally strict when needed.
